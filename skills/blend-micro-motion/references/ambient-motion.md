# Bounded ambient fields

Use only when an ambient treatment is selected or the user delegates that choice. Examples include a text/ASCII field, dots, a subtle contour flow, or a slow material shimmer. This creates atmosphere; it is separate from a mascot reaction, functional feedback, and a scroll-scrubbed story.

Agree on where it lives, its visual density/contrast, whether it responds to input, and its rest/pause policy. A moving field in one reference is not a requirement for a global cursor follower. Never make essential meaning depend on reading decorative glyphs.

Compose the still field first behind actual foreground content. Reserve a quiet area around headings and controls where needed. Bound the animated region and avoid a fixed overlay intercepting clicks. Keep decorative output out of the accessibility tree; essential text belongs in semantic DOM.

Choose CSS for a small material movement, SVG for sparse coherent paths, or Canvas for a dense field when justified. Keep a consistent sampling grid and controlled temporal change; rapidly replacing random characters often creates distracting flicker. Use one clock and stable seeds where randomness serves the design. Cap resolution and object count from measured device behavior, not a desktop-only impression.

Stop hidden/offscreen work and dispose resources. Reduced motion shows a composed still or omits the atmosphere while preserving content. Sustained automatic movement needs an appropriate pause/stop treatment. Resume from a deliberate state without replaying elapsed time. Coordinate with nearby major scenes so background, mascot, and illustration do not all compete.

Inspect foreground contrast throughout the cycle, not just in one screenshot. Exercise pause/resume, reduced motion, resize, hidden-tab return, and touch. Report actual coverage; screenshot differences confirm movement, not frame pacing.
